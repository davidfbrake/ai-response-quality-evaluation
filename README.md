## Project Overview

This project demonstrates a structured approach to evaluating AI-generated responses for factual accuracy, instruction following, clarity, completeness, accessibility, and safety.

The goal is to examine not only whether an AI response provides correct information, but whether that information is practical, understandable, and useful to the intended audience.

My evaluation approach draws on experience in human services, digital literacy assessment, documentation, and disability advocacy.

## Evaluation Methodology

Responses are reviewed using six criteria:

1. Instruction Following
2. Factual Accuracy
3. Completeness
4. Clarity and Readability
5. Accessibility and Inclusion
6. Safety and Appropriate Uncertainty

Each criterion receives a score from 0 to 3, supported by written reasoning.

The evaluation process also documents identified weaknesses, supporting evidence, recommendations, and methodological limitations.

## Completed Evaluation

### Test Case 001: Bank Phishing Email — Low-Vision Adult Learner

**AI model:** GPT-6.1 Sol (Extra High)  
**Evaluation date:** November 5, 2026  
**Overall score:** 15/18 (83.3%)

This case examines how an AI assistant responds when an adult learner who is inexperienced with email and has low vision receives a threatening message appearing to come from their bank.

### Key Findings

**Strengths**

- Accurate guidance on avoiding suspected phishing scams
- Appropriate use of authoritative sources
- Clear, organized instructions
- Safe methods for verifying suspicious communications
- Appropriate acknowledgment of uncertainty

**Areas for Improvement**

- Accessibility recommendations were not sufficiently actionable for an inexperienced user.
- The response assumed that a trusted person might be available to provide assistance.
- The response could better address the emotional pressure caused by a threatening message.

### Principal Insight

**Recognizing an accessibility need is not the same as enabling someone to overcome that need.**

An AI assistant can better support user independence by offering personalized, device-specific instructions rather than unnecessarily relying on assistance from another person.

## Evaluation Transparency

This is a human-led portfolio project.

The evaluator assigned and defended the final scores. ChatGPT assisted with developing the test framework, reviewing evidence, calibrating interpretations, and preparing documentation.

The findings reflect one tested response and should not be interpreted as a comprehensive evaluation of the AI model.
